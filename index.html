Selected Work

Industrial Vision Systems — DESION

Computer Vision Engineering · 2026

Worked on a production multi-camera computer vision system for industrial inspection, including semantic segmentation, dataset preparation, model adaptation, integration, runtime evaluation, and failure analysis.

I also investigated camera acquisition, configuration, reconnect behavior, exposure differences, geometry mismatches, and system-level edge cases. Models were integrated into the production pipeline using GPU-based and ONNX inference.

Semantic Segmentation Multi-Camera Vision PyTorch OpenCV ONNX CUDA Failure Analysis

Portrait Instruction-Guided Color Enhancement (PICE)

Master's Thesis · University of Würzburg

Developed and evaluated a lightweight text-conditioned multimodal model for high-resolution portrait enhancement using PyTorch and neural 3D-LUT supervision.

The work explored natural-language conditioning, efficient model design, architecture variants, and systematic evaluation using reconstruction, perceptual, and color-quality metrics.

Multimodal Vision PyTorch 3D LUT Efficient Deep Learning Image Enhancement Benchmarking

Self-Driving Car Perception

Bachelor Thesis

Developed a real-time visual perception prototype for a small autonomous-driving platform using OpenCV.

The system combined object detection, traffic-sign recognition, lane detection, and real-time camera processing.
